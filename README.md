# ORION 宇宙船帰還ミッション

GitHub Pages 公開用フォルダです。リポジトリのルートに以下を配置してください。

- `index.html` — ストーリー・ミッション一覧
- `module1/index.html` — 通信回路の復旧
- `module2/index.html` — エネルギー制御盤
- `module3/index.html` — 航行システムの復旧

**公開トップURL：** https://cy-toma.github.io/orion-team-building/

公開後は上記URLから開始してください。各モジュールで役割選択画面が開きます。進行役は各モジュールの `?role=host` を開いてください。

全ミッションは従来のゲーム判定・採点・ローカル保存を維持し、共通の上部ナビゲーション、章立て、操作担当のタイマー開始／リセット位置・サイズと共通ステータス表示を追加しました。ブラウザのローカル保存データは既存のキーを維持しています。

## 結果の共有

各ミッションの操作担当画面には「結果をコピー」ボタンがあります。経過時間・スコア・誤操作回数・誤操作減点・時間減点・合計減点を一括でクリップボードにコピーできます。クリア前は途中経過としてコピーできます。
